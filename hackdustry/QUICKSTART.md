# 🚀 HACKDUSTRY - Quick Reference Card

## ⚡ Installation (30 seconds)

1. Copy `hackdustry` folder → Mindustry mods folder
2. Restart Mindustry
3. Look for green **"H"** button!

**Mods folder locations:**
- 📱 Android: `/sdcard/Android/data/io.anuke.mindustry/files/mods/`
- 🪟 Windows: `%APPDATA%/Mindustry/mods/`
- 🐧 Linux: `~/.local/share/Mindustry/mods/`
- 🍎 macOS: `~/Library/Application Support/Mindustry/mods/`

## 🎵 Music Player

### Setup
1. Menu → Music tab → "Show Folder"
2. Copy `.ogg`, `.mp3`, `.wav`, `.flac` files to folder
3. Tap "Rescan"
4. Select track & play!

### Controls
- ▶️ Play
- ⏸️ Pause
- ⏭️ Next
- ⏮️ Previous
- 🔀 Shuffle
- 🔊 Volume

## 🐛 Troubleshooting

| Problem | Solution |
|---------|----------|
| Button not visible | Restart Mindustry completely |
| Mod not loading | Check folder is in mods directory |
| Music not playing | Use .ogg format, rescan folder |
| Cheats not working | Make sure you're in a game |
| Can't move button | Long-press (hold) before dragging |
